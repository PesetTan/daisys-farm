# Daisy’s Farm control icons

Single source: `assets/ui-icons.svg`. All glyphs use a 24 × 24 view box, 1.8-unit rounded strokes, currentColor, and a shared 3–21 drawing area. The replay arc and arrowhead join at the same point. Home, replay, tap, trace, check, arrows, and all four seasonal controls belong to the same set. No Unicode control glyphs.

Action buttons use a 48 × 48 icon frame, 10px icon-to-label gap, equal widths, and a shared 20px label line height. Header icons use a 32 × 32 frame; menu artwork uses an 80 × 80 frame.
